# HoloScript Mini — Frontend UI

A modern frontend interface for HoloScript Mini focused on immersive AI interactions, gesture-driven experiences, and real-time UI experimentation.

## Features

- Modern responsive UI
- Interactive gesture-based controls
- Real-time frontend rendering
- Smooth animations and transitions
- Modular component architecture
- Developer-friendly setup

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- Framer Motion

## Getting Started

### Clone the Repository

```bash
git clone -b frontend-ui --single-branch https://github.com/holoscript-org/holoscript-mini.git
cd holoscript-mini
```

### Install Dependencies

Using npm:

```bash
npm install
```

Or using pnpm:

```bash
pnpm install
```

### Run Development Server

```bash
npm run dev
```

or

```bash
pnpm dev
```

Open:

```txt
http://localhost:3000
```
